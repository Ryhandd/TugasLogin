# Tugas Pemrograman Mobile: Aplikasi Login & Register

Repositori ini berisi proyek Android Studio untuk memenuhi tugas mata kuliah di Semester 4. Aplikasi ini mencakup fungsionalitas dasar autentikasi pengguna.

## 📌 Fitur Utama
* **Register:** Membuat akun baru dan menyimpannya secara lokal/database.
* **Login:** Autentikasi pengguna untuk masuk ke dalam aplikasi.
* **Input Validation:** Validasi sederhana untuk memastikan email dan password terisi dengan benar.

## 🛠️ Teknologi
* **IDE:** Android Studio
* **Bahasa:** Java / Kotlin
* **Komponen:** XML Layouts, Activity, Intent.

## 📂 Struktur Folder
* `app/src/main/java/` : Logika aplikasi (Activity & Logic).
* `app/src/main/res/layout/` : Desain tampilan (XML).

## 🚀 Cara Menjalankan
1. Download atau Clone repositori ini.
2. Buka folder proyek menggunakan **Android Studio**.
3. Jalankan `Gradle Sync` jika diminta.
4. Klik **Run** dan pilih Emulator atau Device fisik.
